# SlopperEngine
SlopperEngine is a fully C# game engine, designed to be flexible and performant.
It supports 3D rendering, physics, basic 2D UI, serialization, clean "scripting", and admittedly rather unsafe mod loading.
Planned features are a fully custom shading language, audio, an editor, and scalable multithreading.

For more information about the design, check out the "Design Justification.md" file.
If you're interested in contributing, check out "Style Guide.md" and "CONTRIBUTING.md" instead.

## Build instructions:
